## Module `qiskit/synthesis/unitary/qsd.py`

Quantum Shannon Decomposition.

Method is described in arXiv:quant-ph/0406176.

## `qs_decomposition`

```python
def qs_decomposition(mat: np.ndarray, opt_a1: bool | None=None, opt_a2: bool | None=None, decomposer_1q: Callable[[np.ndarray], QuantumCircuit] | None=None, decomposer_2q: Callable[[np.ndarray], QuantumCircuit] | None=None, *, _depth=0)
```

Decomposes a unitary matrix into one and two qubit gates using Quantum Shannon Decomposition,
based on the Block ZXZ-Decomposition.

This decomposition is described in Krol and Al-Ars [2] and improves the method of
Shende et al. [1].

.. code-block:: text

      ┌───┐              ┌───┐     ┌───┐
     ─┤   ├─      ────□──┤ H ├──□──┤ H ├──□──
      │   │    ≃    ┌─┴─┐└───┘┌─┴─┐└───┘┌─┴─┐
    /─┤   ├─      ──┤ C ├─────┤ B ├─────┤ A ├
      └───┘         └───┘     └───┘     └───┘

Without the optimizations, the number of :class:`.CXGate`\ s generated by the decomposition
is the same as the unoptimized method in [1]:

.. math::

    \frac{9}{16} 4^n - \frac{3}{2} 2^n

Optimization A.1, which improves [1] and is applied automatically, saves two
:class:`.CXGate`\ s instead of one in each step of the recursion, reducing the CX count by:

.. math::

    \frac{2}{3} (4^{n - 2} - 1).

Optimization A.2, as in [1], decomposes two-qubit unitaries into a diagonal gate and a
two-CX unitary, reducing the CX count by a further:

.. math::

    4^{n-2} - 1.

Since this optimization should not be done if the original unitary is controlled, it is
applied automatically unless the input matrix is equivalent to a controlled
(block-diagonal) unitary.

Hence, the number of :class:`.CXGate`\ s generated by the decomposition with both
optimizations applied is:

.. math::

    \frac{22}{48} 4^n - \frac{3}{2} 2^n + \frac{5}{3}.

.. deprecated:: 2.5.0
    Passing an arbitrary callable as the ``decomposer_1q`` or ``decomposer_2q`` argument is
    deprecated. Only instances of :class:`.OneQubitEulerDecomposer` and
    :class:`.TwoQubitBasisDecomposer`, respectively, will be accepted from Qiskit 3.0.

Args:
    mat: unitary matrix to decompose
    opt_a1: this argument is deprecated; the optimization is applied automatically when
        ``None`` (the default).
    opt_a2: this argument is deprecated; the optimization is applied automatically when
        ``None`` (the default).
    decomposer_1q: optional 1Q decomposer, an instance of
        :class:`~qiskit.synthesis.OneQubitEulerDecomposer`. If ``None``, the default
        one-qubit decomposition is used.
    decomposer_2q: optional 2Q decomposer, an instance of
        :class:`~qiskit.synthesis.TwoQubitBasisDecomposer`. If ``None``, the default
        two-qubit decomposition is used.

Returns:
    QuantumCircuit: Decomposed quantum circuit.

References:
    1. Shende, Bullock, Markov, *Synthesis of Quantum Logic Circuits*,
       `arXiv:0406176 [quant-ph] <https://arxiv.org/abs/quant-ph/0406176>`_
    2. Krol, Al-Ars, *Beyond Quantum Shannon: Circuit Construction for General
       n-Qubit Gates Based on Block ZXZ-Decomposition*,
       `arXiv:2403.13692 <https://arxiv.org/abs/2403.13692>`_
